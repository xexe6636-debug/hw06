## 任务二：短视频选题简介

### 📌 视频题目

**《具身智能改变未来》**

### 🎯 选题方向

围绕 **具身智能（Embodied AI）** 主题，探讨具身智能与传统 AI 的本质区别，以及它如何赋予机器人"感知—理解—行动"的完整能力闭环。

### 📋 内容概要

| 段落 | 时长 | 内容摘要 |
|------|------|----------|
| 开头 | ~30 秒 | 以一段人形机器人完成家务的视频片段引出主题，提问："机器人真的能理解世界了吗？" |
| 主体 | ~2 分钟 | ① 什么是具身智能：身体 + 感知 + 决策的一体化 <br>② 与传统 AI 的区别：从"会说话"到"会做事" <br>③ 关键技术介绍：多模态感知、强化学习、仿真训练 <br>④ 代表性产品点评：Boston Dynamics、Figure 01、宇树科技等 |
| 结尾 | ~30 秒 | 总结具身智能的发展潜力，展望其在医疗、家庭、工业中的应用，发起互动："你认为机器人会取代人类吗？" |

### 🛠️ 制作说明

- **录制工具**：手机横屏录制
- **剪辑工具**：剪映
- **时长**：约 3 分钟
- **格式**：`.mp4`
